# Changelog

## 1.1.0
- Searching (box or right-click) moves the chests holding the item to the top of the Storage window. / A busca (caixa ou clique direito) leva para o topo os baús que têm o item.
- New *Filter* button in the Storage window: show only the chests with one tag. / Novo botão *Filter* na janela Storage: mostra só os baús com uma tag.
- Ctrl + click moves now show a short list under your bag with the item and the chest it went to. / Os movimentos com Ctrl + clique agora aparecem numa listinha embaixo da bolsa, com o item e o baú para onde ele foi.
- Much less stutter when splitting a stack or opening the Storage window with many chests. / Bem menos travada ao dividir um stack ou abrir a janela Storage com muitos baús.

## 1.0.0
- First release. / Primeira versão.
- Storage window with every chest nearby, search, chest tags and names, Fill tags, sort, stack, restock, slot locks and favorites. / Janela Storage com todos os baús próximos, busca, tags e nomes de baú, Fill tags, organizar, empilhar, reabastecer, espaços travados e favoritos.
